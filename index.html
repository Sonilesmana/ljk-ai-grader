Cara dapat API Key gratis (± 1 menit)

  1. 1. Buka Google AI Studio lalu login dengan akun Google Anda.
  2. 2. Klik Create API key → pilih atau buat project → salin kunci AIza….
  3. 3. Tempel di kolom atas, pilih model, lalu klik Simpan. Kunci hanya tersimpan di browser ini.
